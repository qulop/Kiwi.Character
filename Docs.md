# Main Idea

This is Character.AI analogue, which is using LM Studio as local models provider. The system is using OpenAI endpoints like:
+ GET - /v1/models
+ POST - /v1/responses
+ POST /v1/chat/completions
+ POST - /v1/completions
+ POST - /v1/embeddings
